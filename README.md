## 👋 About Me

I'm a software engineer based in **Bandung, Indonesia**, currently working as a **Frontend Developer at Telkom University**. My daily work sits at the intersection of engineering rigor and real institutional impact: I build and maintain internal applications that thousands of campus users depend on — letter circulation, records management, legal documents, and reporting.

Beyond the day job, my GitHub is a consistent public record of deliberate practice. Across **100+ repositories** I've explored the full breadth of modern software: frontend frameworks (Angular, React, Next.js, Svelte, Vue, Qwik, Astro), backend ecosystems (Laravel, Spring Boot, NestJS, Go, Bun/Hono, CodeIgniter, Symfony, Yii2, Slim), mobile development (Kotlin, Java/Android), and applied machine learning (TensorFlow, OpenCV, scikit-learn).

I care about clean architecture, reusable components, careful refactoring, and shipping things that actually work in production.

## 🧭 How I Work

> **Ship small, refactor often, document everything.**

- **Component-first thinking** — extract reusable pieces before they become copy-paste debt.
- **Type safety as documentation** — TypeScript not as an obligation, but as a design tool.
- **Server-driven where it fits** — HTMX, server actions, and minimal JS when the problem calls for it.
- **Production is the spec** — deployment issues (MIME types, cookies, CORS, caching) are part of the job.
- **Learn by building** — every framework on this profile is backed by at least one working repository.
